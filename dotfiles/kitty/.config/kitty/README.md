# Kitty

Configuração mesclada com o módulo `amonetlol/sh/modules/kitty-tab.sh`.
Mantém CodeNewRoman Nerd Font 12, o tema Catppuccin Frappe e os ajustes existentes.
`tabs.conf` acrescenta abas numeradas, painéis e atalhos do módulo.

- Ctrl+Shift+T: nova aba (barra visível a partir de duas abas).
- Alt+Esquerda/Direita: aba anterior/próxima.
- Alt+Cima/Baixo: criar/fechar aba.
- Alt+1…9: selecionar aba; Alt+R: renomear.
- Alt+H/V: criar painel horizontal/vertical.
- Ctrl+Alt+Setas: redimensionar painel; Alt+C: fechar painel.
- Alt+F: ampliar/restaurar painel; Alt+K: selecionar painel.
- Ctrl+F: pesquisar no terminal.
- Super+/: guia de atalhos em Rofi.

Os helpers ficam no mesmo diretório. Copiar esta pasta para `~/.config/kitty`.
Recarregar o Kitty com Ctrl+Shift+F5 ou abrir uma nova janela.
